typedstandards-publish-example

This site serves signed Typed Standards records published from a hosted notebook and a local Marimo app, each with one call to the typedstandards Python package. Each record's bundle carries the signed package, and any verifier can check it.

Records

Each record's name was chosen before it was signed, so its verifier link is known in advance. A link answers 404 until its record is published. records.json states each record's status, and a withdrawn record's reason.

  • colab-example, the first run of the hosted notebook: verify this record, the bundle
  • marimo-example, the local Marimo app: verify this record, the bundle
  • colab-example-rerun, the notebook's rerun, which revises the first run: verify this record, the bundle

For verifiers

  • records.json, the index
  • .well-known/typed-publisher.json, the signing key
